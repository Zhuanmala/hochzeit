## 不建议优先选的项目

- `12000 元/分钟` 的机器人方案：如果只是婚礼门迎和舞蹈，单价太高，除非它包含非常强的定制演出内容。
- 智元 A3、远征 A2 旗舰版等高价方案：可以作为备选，但需要商家提供婚礼实拍视频证明效果，不建议只看价格表直接定。
- 不同型号机器狗混搭：能用，但视觉统一和同步动作一般不如两台同型号。

## 商家必须确认的问题

- [ ] 人形机器人是否能跳舞，能跳几分钟。
- [ ] 是否能按指定婚礼音乐编排动作。
- [ ] 是否能做门迎互动，例如挥手、说祝福语、合影。
- [ ] 2 台机器狗是否同型号、同颜色、同动作库。
- [ ] 是否包含操作员，几个操作员。
- [ ] 是否包含运输、安装、调试、彩排。
- [ ] 提前多久到场调试。
- [ ] 设备续航多久，是否有备用电池。
- [ ] 室内地面、台阶、地毯、灯光、音响是否影响机器人运行。
- [ ] 表演失败或设备故障时如何处理，是否有备用设备。
- [ ] 是否可以提供婚礼现场真实案例视频。
- [ ] 总价是否含税、合同、发票或收据。

| 关键要求 | 必须确认酒店/场地允许飞行，必须有熟练飞手，必须提前彩排 |

## 无人机必须确认的问题

- [ ] 是室内飞还是室外飞。
- [ ] 酒店/婚礼场地是否允许无人机飞行。
- [ ] 飞行路线是否避开宾客头顶、灯架、喷花、气球、吊顶和屏幕。
- [ ] 是否由专业飞手操作。
- [ ] 是否有保护罩、保险绳或低风险承载方式。
- [ ] 戒指用真戒指还是道具戒指。
- [ ] 真戒指的备用交付方案由谁负责。
- [ ] 彩排时间和失败后的替代流程。

## 当前倾向

如果目标是“有科技感、能互动、预算不失控”，优先考虑：

- 宇树 U2 开放舞蹈版 1 台。
- 宇树 GO2 机器狗 2 台。
- DJI 无人机送戒指，但真戒指建议由人兜底，避免飞行失误造成丢失或损坏。
